Barbie

As Senior Technical Artist at Mindshow I woked on numerous Barbie projects for Mattel.

Rendering Pipeline

Led the technical transition from Unity 2023 URP to Unity 6 URP/HDRP, balancing enhanced visual fidelity with VR performance requirements. This upgrade taught me to navigate complex technical constraints while maintaining creative vision, requiring deep understanding of both rendering pipelines and their performance implications for VR directors.

Lighting

Developed expertise in matching CG lighting to background plates, learning to achieve photorealistic integration between 3D ape characters and live-action footage. This process refined my understanding of light behavior, color temperature, and the technical nuances of achieving seamless compositing in Unity HDRP.

Keyword Driven Shaders

Authored and maintained all key shaders compatible with both URP VR and HDRP pipelines. Developed a JSON-based parameter system that enabled one-button application of custom shader settings, learning to create flexible, artist-friendly tools that streamline complex technical processes while maintaining consistency across different rendering contexts.

Editor Tools

Developed custom C# editor tools in Unity for rapid asset conversion and fixes during the URP-to-HDRP transition. This challenge taught me to identify repetitive technical problems and create automated solutions that save production time while ensuring consistency across hundreds of scene assets and character rigs.

Value

This project taught me to think systematically about pipeline architecture, balancing technical innovation with production reality. I learned to anticipate workflow bottlenecks, create proactive documentation systems, and develop tools that empower artists while maintaining technical standards. Most importantly, I discovered how to serve as a technical translator, ensuring creative vision remains intact through complex technical transitions.
